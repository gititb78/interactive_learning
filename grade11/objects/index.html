תכנות מונחה עצמים (OOP)

הכרות ראשונית עם מחלקות - מחלקת תלמיד (Student)

מגמת מדעי המחשב
מבואות עירון
מורה: גיתית

למה בכלל צריך "עצם" מסוג תלמיד?

עד כה, כדי לשמור נתונים על תלמיד אחד היינו צריכים להגדיר המון משתנים נפרדים:

  • משתנה למחרוזת השם (name)
  • משתנה לגיל (age)
  • משתנים נפרדים לכל ציון (math, english, computers)
במקום לפזר את המידע, מחלקה מאפשרת לנו לארוז את כל המידע שקשור לאותו אובייקט תחת קורת גג אחת, וליצור תבנית מסודרת שנקראת "עצם" (Object).

1. הגדרת התכונות (private)

class Student { private string name; private int age; private string address; private int math; private int english; private int computers; }
התכונות (Attributes) מתארות את המצב של העצם.
אנו משתמשים במילת המפתח private (פרטי). המשמעות היא שלא ניתן לגשת לתכונות האלו ישירות מחוץ למחלקה – זוהי "הכמסת נתונים".

2. פעולה בונה (Constructor)

public Student(string name, int age, string address, int math, int english, int computers) { this.name = name; this.age = age; this.address = address; this.math = math; this.english = english; this.computers = computers; }
חובה! הפעולה שבונה את העצם בזכרון.
לא מחזירה ערך (אין void ואין טיפוס החזרה), היא מחזירה בעצמה את העצם שנוצר.
שמה זהה בדיוק לשם המחלקה.
המילה this מבדילה בין התכונה של העצם לבין הפרמטר שהתקבל.

3. פעולות Get ו-Set

public string GetName() { return this.name; } public void SetMath(int math) { this.math = math; }
מאחר והתכונות מוגדרות כ-private, אנו מספקים פעולות "ציבוריות" (public) כדי לגשת אליהן.
Get: פעולה שמחזירה את הערך של התכונה (שליפה).
Set: פעולה שמקבלת ערך ומעדכנת את התכונה (השמה). פעולה זו תמיד תהיה מסוג void.

4. פעולות לוגיות (לפי דרישה)

public double GetAverage() { return (this.math + this.english + this.computers) / 3.0; } public void IncAge() { this.age++; }
אלו פעולות שמבצעות חישובים או פעולות ספציפיות על התכונות של העצם הנוכחי.
בדוגמה: חישוב ממוצע הציונים של התלמיד, או פעולה פשוטה שמגדילה את גיל התלמיד בשנה.

5. פעולת תיאור - ToString

public override string ToString() { string s = "Name:" + this.name; s += " Age:" + this.age; s += "\nMath Grade:" + this.math + " English Grade:" + this.english + " Computers Grade:" + this.computers; return s; }
זוהי פעולה מיוחדת המחזירה מחרוזת (string).
תפקידה לאסוף את הנתונים המרכזיים של העצם ולהחזיר אותם כטקסט קריא.
המילה override מסמנת שאנחנו "דורסים" את הפעולה המקורית הקיימת בשפה, ונותנים לה משמעות מיוחדת עבור התלמיד שלנו.
