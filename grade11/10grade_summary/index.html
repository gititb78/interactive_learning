הגרלת מספרים (Random)

כדי להגריל מספרים, אנחנו מבצעים תמיד שני שלבים:

  1. יצירת עצם (אובייקט) מסוג Random (נעשה פעם אחת בתוכנית).
  2. שימוש בפעולה Next כדי להגריל מספר בטווח מסוים בכל פעם שנצטרך.

// 1. הגדרת האובייקט (נעשה פעם אחת)
Random rnd = new Random();
// 2. הגרלת מספר שלם (למשל: בין 1 ל-10 כולל)
// המספר השני הוא הגבול העליון ולא כולל אותו
int num = rnd.Next(1, 11);
Console.WriteLine("The random number is: " + num);

פעולת המודולו (%) - שארית

פעולת המודולו לא מחזירה את תוצאת החילוק, אלא את השארית.

שני השימושים הקריטיים שלנו למודולו:

  • מודולו 2 (% 2): לבדיקת זוגיות.
    אם num % 2 == 0 אז המספר זוגי. אחרת, הוא אי-זוגי.
  • מודולו 10 (% 10): למציאת ספרת האחדות.
    למשל, 138 % 10 מחזיר 8. זו הדרך שלנו "לפרק" את המספר.

17 % 5 = ?
24 % 2 = ?
138 % 10 = ?
8 % 10 = ?
10 % 3 = ?
100 % 10 = ?

מבנה לולאת while (עם תנאי קלט)

שימו לב לסדר הפעולות: קליטה ראשונה לפני הלולאה, ואת הקליטה הבאה נמקם בדיוק בסוף הלולאה, כדי לקדם אותה.


Console.WriteLine("Enter a number (-1 to stop):");
int num = int.Parse(Console.ReadLine()); // קליטה ראשונה
while (num != -1) // בדיקת תנאי הלולאה
{
    // --- לוגיקה וחישובים ---
    Console.WriteLine("You entered: " + num);
    
    // קליטה נוספת - הצעד האחרון בתוך הלולאה!
    Console.WriteLine("Enter next number:");
    num = int.Parse(Console.ReadLine());
}

פעולות (פונקציות) - מחזירות ערך

בכותרת מצוין הטיפוס שחוזר (למשל int). הפעולה חייבת להסתיים ב-return. בעת הזימון ב-Main, חובה לשמור את הערך או להשתמש בו (למשל להדפיס).


// הגדרת הפעולה (למשל: סכום)
public static int Sum(int num1, int num2) 
{
    int result = num1 + num2;
    return result; // החזרת הערך
}
public static void Main(string[] args) 
{
    // הזימון: "תופסים" את הערך המוחזר לתוך משתנה
    int total = Sum(5, 7); 
    Console.WriteLine(total);
}

פעולות - לא מחזירות ערך (void)

בכותרת כתוב void (ריק). הפעולה מבצעת משימה אבל לא מחזירה כלום למי שקרא לה. ב-Main, מזמנים אותה כפקודה עצמאית לחלוטין.


// הגדרת הפעולה
public static void PrintGreeting(string name) 
{
    Console.WriteLine("Hello " + name + "!");
}
public static void Main(string[] args) 
{
    // זימון הפעולה כמשפט עצמאי
    PrintGreeting("Class 11");
    PrintGreeting("Gitit");
}
